# Skills de la agencia ProTeam (procedimientos profesionales, 16/11)

Una **skill** es un procedimiento con criterios, ejemplo y control. Una **herramienta** es lo que ejecuta (ffmpeg, OpenCV, Windsor, Playwright…). Cada archivo dice qué herramientas usa y cuáles están comprobadas.
Las skills se comparten por el repositorio: cualquier agente puede abrir la de otro cuando su fase lo pida.
