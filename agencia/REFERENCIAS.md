## Cómo se revisa
- Búsqueda web (WebSearch/WebFetch) de las cuentas y de sus Reels más vistos; Instagram a menudo bloquea la lectura directa: si no se puede, se apunta como pendiente y se pide a Biel enlaces o vídeos.
- Vídeos que Biel pase: análisis fotograma a fotograma (hook, ritmo, cortes, texto, sonido).
- Opcional: `virality_predictor` de Higgsfield para comparar el gancho de una referencia con el nuestro (gasta créditos; usar con cabeza).
