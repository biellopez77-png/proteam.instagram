Reel: T01-1-r3 «Trece mil para siete» (fútbol). Guion: `agencia/fabrica/guiones/T01-1-r3.md`.

- Carrusel 1080×1440, 6 láminas (`c1`…`c6`): portada «La primera vuelta es tu base de datos.» con el papel de Lehmann enmarcado → problema (vuelves a jugar contra él y no recuerdas qué te hizo; calendario con hilo octubre → enero) → paso 1 al acabar, tres líneas del rival (el peligroso, la banda, el balón parado) → paso 2 la ficha en la semana de la vuelta → paso 3 léelas antes de preparar el partido → resumen + «Guárdalo y pásaselo a tu segundo».
